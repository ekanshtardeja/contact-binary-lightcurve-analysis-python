# Binary Star Analysis Tools

A collection of reusable Python tools for the analysis of eclipsing and contact binary star systems.
This repository contains scripts developed during my research and learning in observational astrophysics. The tools are designed to automate common tasks in binary star light curve analysis.

## Current Tools
### 1. Time of Minima (ToM) Finder

Determines the time of primary and secondary minima from observational light curve data.

Features:
- Reads observational light curve data
- Fits eclipse minima
- Estimates Time of Minima (ToM)
- Produces publication-quality plots


### 2. PHOEBE Synthetic Light Curve Generator

Generates synthetic binary star light curves using PHOEBE.

Features:
- Creates contact binary models
- Adjustable stellar parameters
- Synthetic light curve generation
- Export to CSV for further analysis
